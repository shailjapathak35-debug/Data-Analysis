# Data-Analysis of Diabetes
Diabetes Data Analysis
This project focuses on exploring and analyzing a diabetes dataset using Python and Pandas.

## 📌 About the Project

The dataset contains information such as pregnancies, glucose level, blood pressure, skin thickness, insulin, BMI, diabetes pedigree function, age, and diabetes outcome.

The project includes basic dataset exploration and understanding of the data using Python.

## 🛠️ Technologies Used

- Python
- Pandas
- Google Colab
- Jupyter Notebook

## 📊 Dataset

The dataset contains **768 records and 9 columns**:

- Pregnancies
- Glucose
- BloodPressure
- SkinThickness
- Insulin
- BMI
- DiabetesPedigreeFunction
- Age
- Outcome

## 🔍 Analysis Performed

- Imported the dataset using Pandas
- Viewed the first and last records
- Checked the shape of the dataset
- Examined column names
- Checked data types
- Explored the structure of the dataset

## 📁 Files

- `Untitled0.ipynb` – Jupyter/Google Colab notebook containing the analysis
- `diabetes.csv` – Dataset used for the analysis

## 🎯 Objective

The main objective of this project is to practice basic data exploration and understand the structure and features of a real-world dataset using Python.


# Data-Analysis of Crime

Crime Data Analysis This project focuses on exploring and analyzing a crime dataset using Python and Pandas.

## 📌 About the Project

The dataset contains information related to crime records, including details about different crime-related attributes.

The project focuses on exploring the dataset, understanding its structure, analyzing the data, and extracting useful insights using Python and Pandas.

## 🛠️ Technologies Used

- Python
- Pandas
- Google Colab
- Jupyter Notebook

## 📊 Dataset

The dataset contains crime-related records and multiple features that can be used to analyze crime patterns and trends.

## 🔍 Analysis Performed

- Imported the dataset using Pandas
- Viewed the first and last records
- Checked the shape of the dataset
- Examined column names
- Checked data types
- Explored the structure of the dataset
- Performed data filtering and analysis
- Analyzed crime-related patterns and trends
- Extracted useful insights from the dataset

## 📁 Files

- `Crime_DataAnalysis.ipynb` – Jupyter/Google Colab notebook containing the analysis
- `crime_dataset_india.csv` – Dataset used for the analysis

## 🎯 Objective

The main objective of this project is to explore and analyze crime data using Python and Pandas, understand crime-related patterns, and gain practical experience in data analysis.
